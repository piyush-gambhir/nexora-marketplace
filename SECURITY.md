# Security

Nexora is a frontend prototype and does not currently implement production
authentication, payments, or data persistence.

Please report security issues privately through GitHub's **Report a
vulnerability** feature instead of opening a public issue. Include the affected
route or component, reproduction steps, and the expected impact.

Deployers are responsible for implementing server-side authorization, input
validation, secure session management, secrets handling, payment-provider
verification, rate limiting, and appropriate privacy controls.
